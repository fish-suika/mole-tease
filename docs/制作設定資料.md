## 0. 面白さの分析（分解・考察・再構築）

**分解：モグラ叩きを逆から見ると何が面白いか**
1. 立場が逆になるおかしさ：いつも叩く側だった遊びで、叩かれる側になる。説明なしで分かる
2. 空振りの気持ちよさ：振り下ろされたハンマーが、引っ込んだ直後の穴を叩く「スカッ」
3. 人間の反応：ムキになる大人、悔しがる子ども。相手が感情を出すほど、からかっている実感が出る
4. 欲張りと危険：出ていれば点が入るが、出ているほど狙われる

**考察：ゲームにすると何が問題か**
- 隠れていれば絶対に安全 → 隠れ続けるのが正解になる。**出ていないと点が入らない**（本人決定）で、出る理由を作る
- 毎秒の点だけだと「安全そうな時だけ出る」単調な遊びになる → **ギリギリで空振りさせるほど得**にする。からかう笑い（本人決定）と点数の欲がそろう
- 人間がずっと同じだと飽きる → **怒りが上がるほど人間が変わっていく**エスカレート（テーブルクロス名人の「載る物のエスカレート」と同じ考え方）と、**毎回ちがう人が来る**（本人決定）。1回の中では怒りで変わり、遊ぶたびに相手の癖が変わる

**再構築**
- 核は **「ハンマーが来るギリギリまで顔を出して、引っ込んで空振りさせる」1本指の駆け引き**
- 空振りさせるたびに人間の怒りが上がり、点の倍率・人間の反応・攻撃の激しさが一緒に上がる。からかうほど点が増え、からかうほど危なくなる
- 相手の癖を見抜いて付き合い方を変える（せっかちな子は早めに引く、フェイントの多い人は待つ…）のが、遊ぶたびの攻略になる

## 1. ゲーム概要

- タイトル：叩かれないモグラ（仮）
- ジャンル・視点：反射と駆け引きのアクション／3D・モグラ叩き台の手前やや上から
- コンセプト：**モグラ叩きを、モグラ側で。ギリギリで引っ込んで、人間をムキにさせろ**
- 目指す楽しさ：空振りさせた瞬間の「スカッ」／ムキになっていく人間の顔／ギリギリまで出て点を稼ぐ欲張り／今日は誰が来たかのおかしさ
- 基本の体験：穴を押して顔を出す → 人間がハンマーを振りかぶる → ギリギリで指を離して引っ込む → 空振り、人間が悔しがる → また顔を出す

## 2. ゲーム内容

**プレイヤーの役割**：モグラ叩き台の中のモグラ 1匹

**基本操作**（1本指）
- 穴を押している間、その穴から顔を出す。指を離すと引っ込む
- 別の穴を押すと、地下を移動してそこから出る（移動に少し時間がかかる。0.2 秒前後）
- PC はマウスで同じ（押している間だけ出る）

**基本ルール**
- 穴は 3×3 の 9 個（縦画面に収まる数。Claude 案）
- 顔を出している間だけ点が入る。隠れている間は何も起きない（罰はない）
- 人間はモグラが出ている穴を狙う。**振りかぶり（予備動作）→ 振り下ろし** の順で、振りかぶりを見て引っ込めば避けられる
- 叩かれたらたんこぶ 1つ。3つで終わり
- 60 秒たったら人間の負け（逃げきりクリア）

**3人の人間**（毎回ランダムに 1人。中身は Claude 案。遊びながら調整）

人間の反応は文字を出さず、顔（目・眉・口・顔色）と体の動きだけで見せる。

| 人 | 見た目 | 叩き方の癖 | 攻め方のヒント |
|---|---|---|---|
| せっかちな子ども | 帽子、小さい体で台に身を乗り出す | 振りかぶりが短くて速い。そのかわり狙いが雑で、ときどき隣の穴を叩く | 早めに引っ込む。粘りすぎない |
| 負けず嫌いのおじさん | ネクタイ、メガネ | 最初からフェイント（振りかぶって止める）が混ざる。怒りが下がりにくい | 振り下ろしを見るまで待つ。焦って引っ込むと損 |
| 正確なおばあちゃん | 割烹着、丸メガネ | 振りかぶりはゆっくりだが、引っ込んだ穴の上でしばらくハンマーを構えて待つ（待ち伏せ） | 同じ穴から出直さず、別の穴へ移る |

- 3人の難しさはだいたいそろえる（誰が来ても自己ベストを狙える）
- 子どもは怒りが上がりやすく下がりやすい、おじさんは下がりにくい、など怒り方も人ごとに少し変える

**怒りゲージとエスカレート**（からかう笑いの中心）
- 空振りさせると怒りが上がる。**振り下ろしの直前に引っ込むほど（ギリギリなほど）大きく上がる**
- 点の倍率 ＝ 怒りの段階（×1 → ×2 → ×3 …）
- 段階の流れは 3人共通。表情や身ぶりの出し方だけ人ごとに変える（例：段階 4 で子どもは地団駄、おじさんはネクタイをゆるめる、おばあちゃんは割烹着の袖をまくる）

| 段階 | 人間の様子（顔と動き） | 攻撃の変化 |
|---|---|---|
| 1 平静 | にこにこ、楽しそう | その人の癖どおり |
| 2 むっ | 眉がよる、首をかしげる | 振りかぶりが速くなる |
| 3 ムキ | 顔が赤い、腕まくり、身を乗り出す | フェイントが増える（おじさん以外にも混ざる） |
| 4 激怒 | 湯気、台をバンバン叩く | ハンマーが巨大化。隣の穴まで届く |
| 5 錯乱 | 目がぐるぐる、両手にハンマー | 2本同時。ばかばかしさ優先 |

- 叩かれると怒りが少し下がる（人間がすっきりする）。「当てられたら、また落ち着いた人間からやり直し」になり、逆転の余地が残る

**ゲームの流れ**
1. タイトル（自己ベスト表示）→ タップで開始。前置きは短く
2. 今回の人間が台の前にやって来て、コインを入れて 60 秒スタート（誰が来たかを最初に見せる）
3. たんこぶ 3つ、または 60 秒で終わり → 結果画面（今回の人・点数・最大の怒り段階・空振りさせた回数・自己ベスト・もう一回・X 共有）
4. 逃げきったときは全員共通のオチ：**ハンマーを台に置き、肩を落としてとぼとぼ去っていく**。叩かれて終わったときは、人間がガッツポーズして満足げに去る

**攻略・工夫の要素**
- 振りかぶりを見てからどこまで粘るか（ギリギリほど得）
- 相手の癖を見て付き合い方を変える（3人の表の右列）
- 怒りが上がるとフェイントや範囲攻撃が混ざる。上げすぎると危ない
- 狙われている穴から離れた穴へ移動して出直す

**必要な演出・フィードバック**（ノーリアクションをなくす・誇張する）
- 空振り：ハンマーが空の穴を叩く「スカッ」＋土ぼこり、人間の悔しがる顔と身ぶり（台を見つめる、頭を抱える）。ギリギリならスローと強めの効果（プレイヤー向けの「紙一重」表示は UI として出してよい）
- 叩かれた：ピコッ（モグラ叩きらしい音）、モグラの目がぐるぐる、たんこぶ表示、人間のガッツポーズ
- 怒りが上がる：人間の顔色・表情・身ぶり・効果音が段階ごとに変わる。段階が上がった瞬間は短く寄る

## 3. 制作方針

- 使用環境・技術：ブラウザ（HTML＋JavaScript、three.js r128 を CDN から）。`src/` 分割＋`sh build.sh` で 1枚の HTML に結合
- 素材・制約：three.js の基本形状を組み合わせて作る（台・穴・モグラ・ハンマー・人間の顔と上半身）。効果音は Web Audio で合成。人の声は使わない
- 見た目の方向性：ゲームセンターのモグラ叩き台のおもちゃ感。台はつやのあるプラスチック、モグラは丸くてかわいい。人間はデフォルメした大きな頭と腕で、表情がはっきり変わる。3人は帽子・ネクタイ・割烹着など、ひと目で分かる小物で描き分ける
- 操作・カメラ：縦画面の下側に台（9 個の穴）、上側に台の向こうからのぞく人間の顔とハンマー。カメラは台の手前やや上から固定。指で押す穴が下にあり、人間の表情は上で見える配置
- 優先順位：遊べる状態 → 「ギリギリで空振りさせる」が面白いかの確認 → 怒りのエスカレートと 3人の癖 → 人間の反応 → 見た目

## 4. 技術的な実現方法（Claude）

- **当たり判定は数値で決める。** ハンマーの振り下ろしが穴に届く瞬間に、その穴にモグラが出ているか（出る・引っ込む途中を含めた高さ）で判定する。物理エンジンは使わない
- 人間の動き：「狙う穴を選ぶ → 振りかぶり（予告時間）→ 振り下ろし → 戻す（または待ち伏せ）」の状態遷移
- 数値は **人ごとの表 × 怒り段階ごとの表** で持つ（`src/10-config.js` の `CFG`）。人ごと：予告時間・狙いのずれ・フェイント率・待ち伏せ時間・怒りの上がり方／下がり方。段階ごと：予告時間の倍率・フェイント率の加算・届く範囲・ハンマー本数
- 表情は、目・眉・口の形と顔色の切り替え＋体の動き（身を乗り出す・台を叩く・地団駄）の組み合わせで作る。人ごとの違いは小物と身ぶりの差し替え
- 判定ロジック（ギリギリ度・怒りの増減・倍率・点数・たんこぶ・人ごとの癖）は three.js から切り離し、`verify.html` で検証する
- 押している穴の判定は、画面の座標を穴の位置に直して行う（three.js のレイキャストか、画面上の穴の位置で近い方）。指を少しずらしても穴が変わりすぎないようにする
- 自己ベストは全体で 1つ、localStorage（使えないときは保存しないだけで遊べる）
- X 共有：スマホは Web Share API（結果画面の画像付き）、PC は X の投稿画面（文章＋URL）。文章に今回の人を入れる（例：「負けず嫌いのおじさんを 激怒 まで怒らせた」）
- 画面の文章は文節の途中で改行しない

## 5. 仕様上の問題と対応案（Claude・実装前の報告）

| 問題 | 対応案 |
|---|---|
| 隠れ続けるのが正解になる | 出ていないと点が入らない（本人決定）。罰は入れない（本人決定）ので、出て稼ぐ方が必ず点が高くなるよう、倍率の伸びを十分に大きくする |
| 毎秒の点だけだと単調（蚊のステルスゲームの学び） | 点 ＝ 出ていた時間 × 怒りの倍率。倍率はギリギリの空振りでしか上がらないので、「からかう」ほど得になる |
| 予備動作が見えないと理不尽 | 振りかぶりは大きく、影と音でも知らせる。最初の段階は予告を長く。せっかちな子どもでも、反応できる長さは下回らない |
| ランダムで来る人によって点が出やすさが違うと不公平 | 3人の難しさをそろえる。verify.html で同じ操作の流れを 3人に当てて、点の出方を比べる |
| 文字を出さないと、人間が怒っているのが伝わりにくい | 顔色（赤）・湯気・身ぶりなど、遠目でも分かる大きな変化を段階ごとに必ず 1つ入れる。細かい表情は後回し |
| 指が穴を隠して見えない（スマホ） | 穴を押す位置と顔が出る位置をそろえるが、モグラは指より上まで伸びるように出す。ハンマーは上から来るので、指で見えなくなる範囲が少ない。Phase 1 で実機を見て直す |
| 9 個の穴が縦画面で小さすぎる | 台を画面幅いっぱいに置き、穴の当たり範囲を見た目より広く取る。小さすぎれば 2×3 の 6 個に減らす |
| 3人分の顔と動きの作り込みが重い | 頭・胴・腕の骨組みは共通にして、小物・顔の部品・身ぶりだけ差し替える |

## 6. 完成条件

共通：起動できる／押して出る・離して引っ込む操作が動く／判定と点数・たんこぶが機能する／60 秒の逃げきりかたんこぶ 3つで結果画面まで進める／致命的なバグがない。

この作品の条件：
- **ギリギリで空振りさせる手応え**がある（振りかぶりを見て、狙って避けられる）
- 空振りさせるほど **人間がムキになっていくのが、文字なしで見て分かる**（5 段階の表情・身ぶり・攻撃の変化）
- **3人の叩き方の癖が遊んで分かり**、相手によって付き合い方を変える工夫がある
- 隠れ続けるより、出て・からかって点を稼ぐ方が得になっている
- スマホ縦画面で遊べて、PC でも遊べる。結果画面から X に共有できる

## 7. 実装計画

- **Phase 1：核の最小版**
  3D の台と 9 個の穴、モグラ、ハンマー（人間は簡単な顔だけ、1人分）。押して出る・離して引っ込む・穴の移動。人間が狙う → 振りかぶり → 振り下ろし。当たり・空振りの判定、ギリギリ度、点数、たんこぶ、60 秒、結果画面。判定ロジックの `verify.html`
  → **ここで本人が遊ぶ**（ギリギリで空振りさせるのが面白いか）
- **Phase 2：怒りのエスカレートと 3人の癖**
  怒りゲージと 5 段階。段階ごとの予告時間・フェイント・巨大ハンマー・2本同時。点の倍率。3人の叩き方の癖（速い・雑／フェイント／待ち伏せ）とランダムで来る仕組み。3人の難しさの比較を verify.html に追加
- **Phase 3：人間の見た目・反応と演出**
  3人の見た目（小物）と、段階ごとの表情・顔色・身ぶり。空振りの土ぼこり・スロー、叩かれたときの演出、効果音、登場と退場（逃げきりの共通オチ・叩かれて終わったときの退場）
  → **ここで本人が遊ぶ**（通しで遊べる版）
- **Phase 4：仕上げ**
  タイトル・結果画面、自己ベスト、X 共有、レスポンシブ確認
- **最終チェック → まとめて修正（1回まで）**
